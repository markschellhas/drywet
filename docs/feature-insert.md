New feature idea:
Add support for playback insert so future effects like filter or bitcrush can be added. It's based of these complaints/notes from another implementation:
- "Drywet has no playback insert, so crush runs inside the sink mix. Audio already queued keeps the amount it was mixed with."
- "Drywet has no playback insert, so the low-pass runs inside the sink mix, after crush. Each hit starts from a zero filter state. Audio already queued keeps the cutoff it was mixed with."
